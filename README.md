# Web 2 Exercises

Exercises from the Web 2 course at IPL Vinci (Haute École Léonard de Vinci, Brussels).

## Content

- **`exercises/1.x`**: REST API for a film collection with Express and TypeScript (routes, services, data validation, requests tested with REST Client).
- **`exercises/2.x`**: front-end apps with React, TypeScript and Vite (components, props, state, forms, routing, fetching data from an API).
- **`basic/`**: Express + TypeScript starter used as the base for the API exercises.
- **`tutorials/`**: course tutorials (state, collections, routing, fetch, async/await, authentication).

## Tech stack

- TypeScript
- Node.js, Express
- React, Vite
- ESLint

## Run an exercise

Each folder is a separate project:

```bash
cd exercises/2.15
npm install
npm run dev
```
